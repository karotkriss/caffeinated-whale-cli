```jsx
<Card title="Bench 0" subtitle="/workspace/frappe-bench" actions={<IconButton icon="ellipsis" title="More" />}>
  ...

```

- `padded={false}` for tables and log views, which own their insets.
- `tone="danger"` only for a destructive confirmation surface.
